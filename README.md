# macOS rice dotfiles

Apple Silicon macOS rice built on **Homebrew** (all packages) and **GNU Stow** (config symlinks). Catppuccin Mocha is applied directly in each app config — no Nix, no Stylix.

## Stack

| Layer | Tool |
| --- | --- |
| WM | OmniWM (borders/bar disabled) |
| Bar | sketchybar |
| Borders | jankyborders (`borders`) |
| App hotkeys | skhd |
| Terminal | Ghostty |
| Shell | zsh + starship + plugins |
| Theme | Catppuccin Mocha (static configs) |
| Launcher | Spotlight (temporary) |
| Packages | Homebrew |
| Dotfiles | GNU Stow |

## Requirements

- Apple Silicon (`arm64`)
- macOS 26+ recommended (OmniWM requirement)
- Network for first install

## Quick start

```sh
git clone <this-repo> ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

The installer will:

1. Install Homebrew (if needed)
2. Let you toggle CLI tools, rice components, and GUI apps (`gum`)
3. Write `hosts/<hostname>/features.conf` and a root `Brewfile`
4. `brew bundle` + `stow` selected packages into `$HOME`
5. Start sketchybar / borders / skhd / OmniWM services

Homebrew 6+ requires tap trust for third-party formulae. The installer marks
`FelixKratz/formulae/sketchybar` (and borders / skhd) as `trusted: true` in the
Brewfile and runs `brew trust` before bundling. The sketchybar app font comes
from official `homebrew/cask` (`font-sketchybar-app-font`).

Then follow [docs/PERMISSIONS.md](docs/PERMISSIONS.md).

### Non-interactive

```sh
./install.sh --yes              # current/default flags + brew + stow
./install.sh --yes --no-bundle  # features + Brewfile + stow only
./install.sh --adopt            # stow --adopt for existing files
```

## Layout

```text
packages/          # Stow packages (mirror $HOME layout)
  zsh/             # ~/.zshrc
  git/             # ~/.gitconfig
  ghostty/         # ~/.config/ghostty/
  omniwm/          # ~/.config/omniwm/ + LaunchAgent
  skhd/            # ~/.config/skhd/
  borders/         # ~/.config/borders/
  sketchybar/      # ~/.config/sketchybar/
  starship/ bat/ btop/ gh/ yazi/
hosts/<name>/features.conf
lib/features.sh    # feature flag helpers
Brewfile           # generated by install.sh
configs/wallpapers/
```

Feature flags live in each host’s `features.conf`. Stow package selection and Brewfile contents are derived from those flags.

## Manual restow / rebundle

```sh
brew bundle --file ~/dotfiles/Brewfile
./scripts/restow.sh
# or
stow -d ~/dotfiles/packages -t "$HOME" -R zsh git ghostty
```
